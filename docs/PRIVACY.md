# 隐私与发行边界

## 本公开仓库的范围

本仓库仅发布经筛选的项目源码、依赖锁文件、安全默认配置、运行时提示契约、离线测试、必要的第三方声明、产品文档、合成演示素材及配套前端构建。

本仓库是产品开发、维护和发布的唯一事实来源，日常修改、测试、构建和发布直接在本仓库进行。Private 仅供按需参考历史研发材料，不是安装、开发或发布依赖；不再通过 Private 快照更新 Public。历史材料中的真实数据、凭据和内部交接内容不能因此带入公开仓库。

## 用户本机数据

全新安装不导入示例选购项目或商品。项目、商品、研究结果、设置、浏览器登录资料及日志保存在用户配置的本地目录。忽略规则不能替代实际文件审查，请勿将这些文件提交或分享。

Windows 的特定认证交接数据使用 DPAPI，不代表所有数据库和浏览器资料都被加密。升级时保留原数据和配置，不启动多个实例操作同一数据库。

## 外部访问与 AI

平台采集、图片请求及模型调用可能访问外部服务，本地部署不代表完全离线。AI 研究会发送本次请求需要的目标与证据，启用并获准的图片也可能发送到视觉服务。

视觉连接验证在用户确认后向所选服务发送内置测试图，可能产生费用；它不等于商品图片分析。保存或启用视觉配置不授予商品图片上传权限，图片缓存也不等于已上传模型。项目图片分析另需范围、上传和费用确认，且受服务端执行开关限制，默认启动的服务未开放执行。

基础监控与 AI 研究分别控制。未授权自动研究、也没有发起手动 AI 请求时，不会为分析入库商品调用模型。视觉模型可选，最终购买和实物核验由用户完成。

## 分享与问题报告

不要公开 Cookie、Token、API Key、浏览器配置、账户凭据、真实运行数据库、联系方式、用户本机绝对路径或真实商品截图。报告问题时使用脱敏日志与合成样例；发现泄漏的有效凭据时应撤销或轮换，不能仅删除文件。

## 审查范围

发行前检查文件清单、内容、图片和依赖，并在隔离环境验证；自动扫描无匹配不代表不存在任何隐私风险。`python devtools/release_audit.py HEAD` 可以检查公开 Git 树中的常见风险模式，但不能代替人工复核及完整历史审查。

本版本的实际验证范围见 [VALIDATION.md](VALIDATION.md)，平台操作限制见[账号风险](account-risk.md)。

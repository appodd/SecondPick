# 账号与运行边界

本项目使用非官方浏览器集成和采集适配。平台可能触发登录验证、验证码、限流、访问限制或其他账号保护措施，低频访问也不代表没有账号风险。

- 用户本人完成登录。登录资料保存在本机，不能随源码上传或发给他人。
- 应用按确认的搜索范围运行；改变范围需要重新确认。默认配置含尝试间隔、页数及详情数量限制，实际以运行配置为准。
- 遇到验证码、访问受限、登录失效等信号应停止自动运行，按平台正常流程处理，不绕过验证。
- 默认独立监控引擎关闭，需要准备环境并检查配置。单次运行与持续监控的授权、调度及实际采集状态应分别核对。
- 应用不自动向卖家发消息、议价、收藏、下单、支付或修改账号设置。
- 工作台中的本地收藏或候选管理，不等同于修改闲鱼平台上的收藏状态。
- 监控的卖家主页与发布记录采集默认关闭；明确勾选并确认范围后会增加平台访问，包括卖家商品／评价列表。已有卖家字段分析和 Agent 进一步调查不等于已授权这类额外访问。
- 原始截图、HTML、商品文本、账号标识和运行日志可能包含个人或第三方信息，不应直接上传到公开仓库或问题报告。
- AI 请求会向配置的模型服务发送所需内容；请阅读[隐私说明](PRIVACY.md)。

研究只是对已提供证据的分析，不是验机、真伪保证、卖家信用背书或交易建议的替代。

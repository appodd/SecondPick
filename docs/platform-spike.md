# 平台访问与证据范围

本文件是项目研究提示的静态参考，不是外部平台接口可用性的实时保证。

- 当前主要采集路线是用户授权范围内的闲鱼浏览器访问及独立采集引擎适配，不是闲鱼官方接口服务。
- 淘宝、京东和其他来源可作为人工或研究参考；不能把代码中存在适配器等同于全站稳定可用。
- 搜索结果与已保存商品不代表整个市场；研究应说明样本、时间、目标版本与未覆盖范围。
- 报价是已保存的挂牌记录，不是成交价、实时报价或可购买保证。
- 卖家陈述、平台字段、用户补充和图片观察应分别说明来源，不能把陈述写成已独立验真。
- 遇到验证码、登录失效、限流和访问限制应停止。不能通过扩大账号权限、绕过验证或更改平台保护逻辑完成研究。
- 采集计划须核对范围；模型费用、平台账号风险及最终交易决定由用户知情处理。

本参考不包含真实账号、商品链接、个人路径、运行快照或抓取材料。

## ai-goofish-monitor failure guard

The following files derive from [Usagi-org/ai-goofish-monitor](https://github.com/Usagi-org/ai-goofish-monitor), commit `77f8d75869acd65f9dba72731b95c7c49ea67bdf`:

- `src/shopping_agent/goofish_failure_guard.py`: upstream `src/failure_guard.py`, adapted for a separate lock file, Windows byte-range locking and fail-closed lock errors. Failure policy is retained.
- `tests/fixtures/goofish_failure_handler.py`: upstream `_format_failure_reason` and `_notify_task_failure`, used as an offline integration fixture.
- `tests/fixtures/goofish_upstream/src/services/item_analysis_dispatcher.py`, `seller_profile_cache.py`, and `tests/fixtures/goofish_upstream/src/keyword_rule_engine.py`: unchanged upstream components with license headers, used for offline adapter and subprocess tests. These are not a bundled platform runtime.

`tests/fixtures/goofish_detail_loop.py` derives from `src/scraper.py` at supported runtime commit `f85d140b6b45029d9a0925feb96dad733b41396d`: the native detail navigation, validation, exception handlers and cleanup are retained in an offline harness; successful parsing is replaced with a local callback. `goofish_control_flow.py` applies a narrow, shape-checked in-memory transformation to the external runtime; the reference checkout is never edited.
